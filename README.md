## Deploy to GitHub Pages (under `PegBitStudio`)
1. Create a public repository on GitHub under `PegBitStudio` (for example `pegbitstudio.github.io` for the root URL `https://pegbitstudio.github.io`, or `portfolio` for `https://pegbitstudio.github.io/portfolio/`).
2. From inside this `portfolio/` folder, run:
   ```bash
   git init
   git add .
   git commit -m "Add AI Systems Engineer portfolio"
   git branch -M main
   git remote add origin https://github.com/PegBitStudio/pegbitstudio.github.io.git
   git push -u origin main
   ```
3. On GitHub, go to **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** and save. Your live portfolio will be available in ~1 minute.
