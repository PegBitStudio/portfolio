02 / Open research

AI safety & AI control

Open-source reference implementations, Apache-2.0, on github.com/PegBitStudio.

Can an autonomous AI agent's actions be constrained during execution and independently verified afterwards?

The work pairs Part A — bounded autonomous systems — with Part B — verifiable AI execution: tamper-evident SHA-256 hash chains and offline audit verifiers.

  • Open research benchmarks
  • Witness technical report
pegbit-ai-control-harness

Apache-2.0

Test bed for bounding AI coding agents: strips secrets before a run, scans code for risky patterns, generates seccomp and Docker isolation profiles, and records every run in a hash-chained audit log.

pegbit-witness-research

Apache-2.0

Reference code and an offline verifier for cryptographic SHA-256 hash chains, external checkpoints, and tamper-evident checks of autonomous agent histories.

pegbit-core-loopguard

Apache-2.0

Stateful execution-loop guardrails and bounded delegation so agents cannot run away, escalate tools without authority, or exhaust a budget in silence.

pegbit-anima-calibration

Apache-2.0

Calibration and safeguarding harness that tests whether models signal genuine uncertainty when a decision is consequential and the evidence is ambiguous.
